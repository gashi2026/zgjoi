# English language (i18n)

Zgjoi is bilingual: **Albanian (sq, default)** and **English (en)**.

## URLs and language choice
- Albanian keeps every existing, unprefixed URL (`/kerko`, `/pro/paneli`, …). English is the same page under `/en` (`/en/kerko`).
  `proxy.ts` rewrites `/en/*` onto the same route tree, so there is one set of pages.
- Each page sets `<html lang>`, a canonical URL and `hreflang` alternates (sq, en, x-default); the sitemap lists both versions.
- The language is remembered in the `zgjoi_locale` cookie and, for signed-in users, in `User.locale`.
  - SQ / EN switcher in the header (desktop + mobile menu bar + drawer) and in both footers → `POST /api/locale` (cookie + profile).
  - Login: a saved profile language wins; if the account never chose one, the current language is saved. Sign-up saves the current language.
  - First visit (no cookie): English only when the browser's *top* Accept-Language is English; otherwise Albanian. Crawlers are never redirected.
  - Visiting an Albanian URL with `zgjoi_locale=en` redirects (GET only) to the `/en` version.

## Code
- Messages: `lib/i18n/messages/sq.ts` (source, `MessageKey`) and `en.ts` (typed `Record<MessageKey, string>`).
- Server components / actions / routes: `const t = await getT()` (`lib/i18n/server.ts`). Client components: `const t = useT()` (`lib/i18n/client.tsx`).
  Only the namespaces in `lib/i18n/client-namespaces.ts` are sent to the browser.
- Links: import `Link` from `@/components/i18n/Link` (adds `/en`); `useRouter` from `@/lib/i18n/client`; server redirects via `localRedirect` (`lib/i18n/redirect.ts`).
- Shared/domain code (labels, `AppError` messages, stored notification titles, category names) stays in Albanian and is translated at the edge with
  `t.tx(text)` (catalog keys `lib.*`, `server.*`, `category.*`). API responses (`message`, `error`, field errors) are translated in `lib/server/http.ts`.
- Category names translate through `category.*`; database slugs never change.
- Money, dates and times: `money/dateTime/clockTime(value, t.locale)` — sq-XK / en-GB, always Kosovo time (Europe/Belgrade).
- Emails (verification, password reset, job notices) use the recipient's `User.locale`.

## Tests
`tests/i18n.test.ts` fails when a key exists in one dictionary but not the other, when placeholders differ, or when hard-coded Albanian
appears in a rendered page/component (`tests/i18n-scan.ts`).

## Database
`User.locale` (nullable TEXT, CHECK sq/en): staging `supabase/staging/user-locale.sql` (applied), production `supabase/production/20261129_user_locale.sql` (not applied).
